屏幕贴图 ScreenPin 1.0 —— 交付说明
================================

一、这是什么
把任意图片（png/jpg/gif/svg…）或视频（mp4/mkv/avi/mov…）贴在屏幕上置顶显示的小工具：
- 占最高（置顶，且每 4 秒自动检查、被别的窗口压下去会自动抢回来）
- 随意改大小（滚轮 / 拖右下角或左下角 / 右键菜单精确百分比）
- 吸附到屏幕任意角/边/居中（右键菜单点选，或拖到边上松手自动吸附）
- 半透明（右键 → 不透明度，10%~100%）
- 一切修改都在右键菜单里

二、怎么用
启动：双击「屏幕贴图.exe」（或「启动屏幕贴图.bat」用 python 跑源码）。
选择素材有三种方式：
  1) 启动面板点「选择图片/视频…」按钮
  2) 把文件直接拖到启动面板窗口上
  3) 把文件拖到程序图标上（或命令行传路径），支持一次多个
     第二次再双击 exe 不会开第二个程序，会把文件交给已运行的那个。

素材上的鼠标操作：
  - 左键拖动          = 移动（吸附状态下先拖一下脱离吸附）
  - 右下角/左下角拖动  = 改大小（默认保持宽高比）
  - 滚轮              = 每档放大/缩小 10%
  - 左键单击          = 视频播放/暂停
  - 右键              = 全部设置菜单

右键菜单一览：
  打开…（含最近打开 10 条） / 复制文件路径
  大小（50%~300% 预设、±10%、保持宽高比、隐藏其余只留这个）
  位置（自由、左上、顶部居中、右上、左侧居中、居中、右侧居中、左下、底部居中、右下、适配屏幕90%）
  不透明度（10%~100%、快捷 ±10%）
  播放（播放/暂停、循环播放、静音、音量滑条）
  置顶显示（占最高）开关
  鼠标点击穿透开关
  关闭这个贴图 / 退出 / 关于

三、全局热键
  Ctrl+Alt+P = 一键开/关「点击穿透」（所有贴图一起切换）。
  穿透开时鼠标点击会落到下层窗口，此时无法右键，用这个热键切回来，或右键托盘图标。

四、记住与不记住
  关闭时记住：每个素材文件 + 它的吸附位置。下次启动自动恢复。
  故意不记：窗口坐标（换显示器/换分辨率会跑到屏幕外）和不透明度（每次启动要满不透明，
  避免你忘了它半透明而找不到窗口）。配置文件在 %LOCALAPPDATA%\ScreenPin\config.json。

五、图标与配色来源（如实交代）
  - 图标 pin：Google Material Design Icons「pin」图标，Apache-2.0 许可，
    来源 Templarian/MaterialDesign-SVG 官方仓库（jsdelivr 镜像下载），
    mkicon.py 把它渲染成多尺寸 pin.ico。菜单里没有用任何 emoji/字符拼图标，全是纯文字条目。
  - 配色：素材未就绪时的占位卡为自写的中性灰单色系（深灰底 #18181A + 浅灰字 #D5D5D5），
    右键菜单/音量条/提示条用 Qt Fusion 系统默认风格（本机实际外观取决于系统主题）。
    全程未使用渐变、发光、玻璃拟态等 AI 味效果。
  - 未抄任何现成软件的界面。

六、环境与限制（实测确认）
  - Python 3.11.9 + PyQt5 5.15.11；视频解码**不依赖系统解码器**：
    主后端 = PyAV（pip 包 av，官方 wheel 自带 FFmpeg，独立解码 mp4/mkv/webm/avi 等）；
    若 PyAV 不可用则自动回落 Qt 自带 WMF 后端（要求系统媒体功能完整）。
  - 图片与 GIF 动图同样支持（GIF 按动图播放）。
  - 点击穿透是窗口级的：穿透期间该素材不接受右键/滚轮，这是有意为之。
  - 屏幕录制/受保护视频（DRM）无法显示，属系统限制。
  - 附带 test.mp4（10 秒标准测试片）方便自测。

附：视频后端实现要点（供维护参考）
  - av_player.py：解码线程（demux→decode→rgb24 帧 + s16 PCM）+ 墙钟主时钟
    + QAudioOutput pull 模式（Qt5 无 push write）+ frame_ready/ended/failed 信号。
  - 暂停=冻结解码线程（否则 PCM/帧队列无界增长）；循环=seek(0)+清队+时钟归零。
  - 打包要点：av.libs（25 个 FFmpeg DLL）必须落在 exe 内 av 包同级，
    delvewheel patch 会 add_dll_directory(<av上级>/av.libs)；构建用 --collect-all av。

七、重建
  生成图标：python mkicon.py
  直接运行：python overlay.py
  打包 exe（在 D 盘 ASCII 目录里构建，中文路径不进工具链；bat 内已带 --collect-all av）：
    构建：cmd /c build_exe.bat      （产物 dist\screenpin.exe 复制到本目录即交付版）
  手工等价命令（在 D:\build_screenpin 下）：
    pyinstaller --onefile --noconsole --name screenpin --icon pin.ico --add-data "pin.ico;." --collect-all av --clean overlay.py

八、新增功能（v1.3）
  1) 预设位置（右键「位置」九宫格）：左上角/上方/右上角/左边/居中/右边/左下角/下方/右下角
     + 自由 + 适配屏幕 90%；拖到边缘松手也自动吸附。
  2) 关键帧动画（右键「关键帧」）：给贴图打位置点 →「开始关键帧动画」按点平移（演示动画那种）；
     打点间隔 2 秒、总时长随点数、循环可勾、列表逐条可删、可清空；配置里一起记住。
  3) 文字/符号贴图（托盘或右键菜单「新建文字贴图」）：双击改内容与样式（字号/粗体/底色/文字色取色），
     插入符号页签（箭头/数学/图形/括号/标记/货币）；改大小=字号缩放；随窗口走锚点/透明度/关键帧。
  4) 临时截图热键（默认 Ctrl+Alt+S，可改）：整屏截一张放到设定位置；再按隐藏=从内存释放；
     只存内存绝不落盘（截图窗无文件路径，不进配置）。位置/宽度%/不透明度 在「设置」里改。
  5) 热键可设定（设置框，按新组合键捕获，须带 Ctrl/Alt/Shift/Win）：
     点击穿透默认 Ctrl+Alt+P、截图默认 Ctrl+Alt+S；存在配置里。
  6) 中英切换（设置框「界面语言」）：菜单/提示/对话框/启动面板/托盘全走翻译表，即时生效并记住。
  7) 视频声音：右键「播放」→「静音」开关 + 「音量…」滑条 0-100（两后端都接通）。
  8) 小面板（右下角小任务窗）：**左键点托盘图标** 或 热键（默认 Ctrl+Alt+Q，可在设置里改）开/关；
     一格格按钮=打开/文字/截图/穿透/置顶/中英切换/多图片/设置/关于/退出，下面是当前贴图清单
     （点名字=激活该贴图，右侧 ×=单独关闭）。
  9) 多图片：「选择图片/视频」可**一次多选**全部打开；启动面板可**一次拖多个文件或整个文件夹**；
     托盘「多图片批量设置」勾选多个贴图，批量套用 位置 / 不透明度 / 大小，或一键关闭选中的。

十、临时截图全家桶（v1.5，热键全部可自定义、默认前 3 个有、后 4 个不绑定）
  托盘右键/右键截图都能点，热键在「设置 → 全局热键」逐行点「改」按新组合（须带 Ctrl/Alt/Shift/Win），
  程序自动记住（%LOCALAPPDATA%\ScreenPin\config.json），冲突/非法会拦下提醒：
  1) 临时截图热键   默认 Ctrl+Alt+S   没显示→新截一张入槽并显示；已显示→隐藏（留槽，再按 Ctrl+Alt+S 又截新的）
  2) 保存临时图片热键 默认不绑定       选目录→存 PNG（文件名带时间戳；存盘后内存照常）
  3) 切换临时图片热键 默认不绑定       循环切下一张（最多 16 张纯内存循环，显示 n/m）
  4) 删除临时图片热键 默认不绑定       删当前那张（腾槽位）
  5) 删除全部图片热键 默认不绑定       一键清空全部临时截图（内存全释放）
  右键截图本身：保存临时图片… / 下一张临时图片 / 删除这张临时图片 / 删除全部临时图片（没绑热键就右键点）
  点击穿透热键 默认 Ctrl+Alt+P；小面板热键 默认 Ctrl+Alt+Q——三行也是同处改名后统一叫“××热键”。

九、官网 / 开源页（含下载区）
  路径：web\index.html（单文件、图标内联、零外部请求；开源后整目录推仓库即为 GitHub Pages）。
  下载区（页面 id=download）：
    - 下载安装程序 → web\下载\屏幕贴图-安装程序.zip（约 77MB：安装程序 14KB + 便携版 78MB + 重置程序.bat，解压到同目录运行安装程序）
    - 下载便携版 → web\下载\屏幕贴图-便携版.exe（单文件 78MB，FFmpeg 内置）
  安装程序用法：双击选目录（默认 %LOCALAPPDATA%\Programs\屏幕贴图，免管理员）→ 装入 主程序+重置程序+卸载程序+桌面/开始菜单快捷方式；
    静默：屏幕贴图-安装程序.exe /S "<目录>" 1 1（退出码 0=成功）；卸载：卸载屏幕贴图.exe /uninstall "<目录>"。
  分区：下载 / 功能 14 卡 / 热键 7 行表 / 说明 FAQ / 构建 / 许可与图标来源（MDI Apache-2.0、PyQt5 双许可提醒）。
  文案要求（用户定）：平实、不许 AI 感——不写“赋能/极致/一键搞定”这类话，写具体的：拖角 10% 一档、九宫格点名、截图只进内存。
  图标：Google MDI 14 枚（web\icons\ 下留了源文件），页面内联 <symbol>，用 currentColor 系统色。
