截一张图、拖一个视频进去，它就贴在屏幕角上，别的窗口照样在上面干活。 想多大拖多大，想多透明拖多透明，右键想改什么改什么。

功能Features

都是右键菜单里能点到的东西，没有藏起来的设置页。

图片、视频、GIF 都行

mp4、mkv、webm 这类视频直接播；GIF 照常动；png/jpg 拖进来就贴上。视频解码走自带的 PyAV，不依赖系统解码器。

多大你说了算

拖右下角/左下角改大小，滚轮一档 10%，右键菜单里还有 50% 到 300% 的固定档。默认锁比例，不想锁就取消勾。

九宫格预设位置

左上角、上方、右上角、左边、居中、右边、左下角、下方、右下角，右键一选就吸过去；拖到屏幕边上松手也会自动吸。

半透明

10% 到 100% 十档，也可以一次 ±10%。贴图半透明、右键菜单不透明，调起来不晃眼。

永远在最上面

置顶是默认开着的。每 4 秒回头查一次，被别的窗口压下去就自己抢回来。

临时截图，只放内存

热键一按截整屏，贴到设定位置；最多存 16 张来回切、删、全删，全程不写盘。要留底就右键「保存临时图片」自己选目录。

关键帧动画

给贴图打几个位置点，播放键一按，它就按时间轴平移过去——演示「这个东西从这儿挪到那儿」用的。

文字贴图

新建一块字，双击改内容、字号、颜色、粗体、底色；旁边有箭头、数学、图形这些符号页，点一下就插进去。缩放贴图时字号跟着变。

小面板

左键点托盘图标（或热键）在右下角弹出一格格小任务：打开、文字、截图、穿透、置顶、中英切换、设置……下面还列着当前每个贴图，点名字激活、点 × 关掉。

7 个热键，全都能改

设置里点「改」，按下你想要的组合就行，重复了会拦下来。后 4 个默认不绑定，想要再设，程序帮你记住。

中文 / English

菜单、提示、对话框、启动面板、托盘菜单都走了翻译表，设置里点一下即时切换，重启也记得。

多图一起摆

选文件可以一次多选，文件夹整个拖进来也行。托盘「多图片批量设置」勾选几个贴图，位置、透明度、大小一键统一套上，或者把勾中的全关掉。

后台常驻

关掉所有贴图程序也不退出——托盘图标、热键、小面板一直在。真退出走托盘右键或小面板的「退出」。再双击 exe 不会开第二个，文件交给已在跑的那个。

主题、保存、一键初始化

设置里五套成组配色（深灰/炭黑/雾灰/石板/棕灰），选完「保存设置」落盘；改乱了点「一键初始化」，热键、主题、语言、截图设置全回出厂，配置清空重来。

热键Hotkeys

托盘右键 → 设置，或者小面板 → 设置，逐行点「改」重新按。必须带 Ctrl / Alt / Shift / Win 之一。

说明Notes

  • 启动老把上次的图片打开？默认不会了——v1.6 起「启动时恢复上次的贴图」默认关闭，每次启动自己选文件。想让它记住就去设置里勾回来。
  • 关掉贴图程序就没了？没没没，只是素材关了，程序在托盘常驻：热键、截图、小面板都还能用。真退出见托盘右键「退出」。
  • 更新怎么来？设置里默认开「启动时检查更新」，有新版会弹提示让你去官网下；也可以手动点「检查更新」。地址开源后填进源码 UPDATE_API。
  • 反馈：jjonju361999@qq.com（设置→关于里也有）。
  • 视频没画面怎么办？程序优先用自带的 PyAV 解码，正常都该有画面。真碰上了看右键播放菜单的提示，多半是文件本身的编码问题，换个 mp4 试试。
  • 带 DRM 的流媒体视频贴不了——屏幕录制层面就被挡了，这不是本程序能绕的。
  • 截图会写盘吗？不会。临时截图只在内存里，关程序就没了；只有你自己点「保存」才落盘。
  • 配置存在哪？%LOCALAPPDATA%\ScreenPin\config.json。记的是文件路径、锚点、关键帧、热键、主题、语言；不记窗口坐标——换分辨率时记了反而会把窗口甩到屏幕外。
  • 点击穿透开着时右键没反应是正常的，点穿了嘛。用热键或托盘关掉。

构建Build from source

源码就两个文件加一个图标，Python 3.11 + PyQt5 5.15 环境下两条命令。

pip install PyQt5 av pyinstaller
cmd /c build_exe.bat        # 产物 dist\screenpin.exe，已含 FFmpeg 解码库
  • overlay.py — 主程序：贴图窗口、右键菜单、热键、截图、关键帧、设置、i18n
  • av_player.py — PyAV 视频后端：解码线程 + 墙钟主时钟 + Qt pull 音频
  • test_overlay.py — 离屏断言 117 项（尺寸/锚点/热键/截图槽/配置…）
  • build_exe.bat — 打包脚本（会先检查暂存文件齐不齐，缺模块直接报错退出）
